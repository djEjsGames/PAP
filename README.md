# PAP — Paper Airplane Park

종이를 접어 비행체를 만들고 날려보는 Godot 3D 프로젝트입니다.

## 개발 환경

- Godot 4.7.1 .NET
- 시작 씬: `scenes/park.tscn` (독립 접기 회귀 씬: `scenes/main.tscn`)
- 렌더러: Compatibility (OpenGL), MSAA 2×
- 물리: Jolt Physics, 240 Hz, 물리 보간 활성화
- 창: 1280×720, 최소 640×360, 크기 조절 가능, VSync 활성화

## 실행

Godot 프로젝트 매니저에서 `project.godot`을 가져온 뒤 F5로 실행합니다.

```powershell
& 'D:\Works\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64.exe' --editor --path 'D:\Works\Git\PAP'
```

시작 씬은 이동 가능한 공원 검토본입니다. WASD로 이동하고, 우클릭 드래그로 시선을 돌리며 휠로 거리를 조절합니다.
작업대 왼쪽 종이 상점 근처에서 E → 종이 선택·구매 → 작업대 근처에서 E → 접기 → **접기 마치고 보관** → Tab으로 기체 선택·꺼내기 → Space로 투척 준비 순서입니다.
공원에서 정한 목표 방향·고도각은 준비 중 우클릭으로 조절하며 수치와 방향선으로 표시합니다. 준비 카메라는 기체를 보는 어깨 구도이고, Space/Enter로 게이지 시작·강도 결정·원점 입력을 합니다.
B로 준비/관람을 끝내면 플레이어로 돌아옵니다. 실제 기체는 월드에 남고, 착지 표식 근처에서 E로 같은 기체를 회수합니다.
자세/날개 조정의 축 회전·수치 입력과 바람 설정도 사용할 수 있습니다. 가까운 벽이 막으면 발사하지 않습니다.
새 발견물은 E로 집으면 **살펴보기**에 들어갑니다. 왼쪽 드래그로 3D 모형을 돌리고 휠로 확대하며, 유효한 날개 축이 있을 때 접힌/90° 펼친 모습을 전환합니다.
보관하기는 같은 실물을 보관하고, 다시 놓기/Esc는 원래 위치로 돌려놓으며, 정리하기는 보수 없는 정리 기록을 남깁니다.
내가 던진 기체는 빠르게 회수하고, 보관함의 살펴보기로 다시 관찰할 수 있습니다. 관찰/회전/펼침은 실제 종이·날개 설정을 바꾸지 않습니다.
살펴보기의 **내 도면으로 남기기**는 기존 도면 저장을 사용하며 정리와 별개입니다. 작은 창에서는 오른쪽 설명 영역을 스크롤할 수 있습니다.

공원과 살펴보기의 Ctrl+Shift+D는 공원 상태 덤프, 작업대에서는 기존 접기 덤프를 저장합니다.
공원 HUD는 16px 이상 상태 문자, 18px 하단 행동, 20px 근처 행동 안내와 짙은 배경을 사용합니다.

캐릭터는 [Kenney Animated Characters Protagonists](https://kenney.nl/assets/animated-characters-protagonists)의 skaterMaleA/characterMedium과 실제 idle/run을 적용했습니다.
[동봉 CC0 라이선스](assets/characters/kenney/License.txt)와 [출처·적용 범위](assets/characters/kenney/SOURCE.md)를 보존합니다. 별도 walk/throw 클립은 추가하지 않았습니다.

무료 종이 없이 100코인으로 시작합니다. 종이 상점은 색종이 10·A4 20·신문지 15·4절 도화지 30코인에 한 장씩 판매합니다. 카드는 비교만 하며 구매 버튼에서만 차감합니다. 실물·잔액·공원 비행 기록은 실행 중 세션 범위입니다. 기존 발견 비행기는 그대로 주워 사용할 수 있습니다.
기존 **내 도면**만 영구 저장되며 실물 수정/회수와 별개입니다. 산 종이는 투척·회수 때 비용 없이 다시 사용합니다. 공원 작업대는 재료를 유지하며, 다른 재료의 도면은 맞는 종이를 구매·선택해야 합니다. 무작위 발견물·정식 공원 미술·수입·판매는 후속 범위입니다.

작업대에서는 기존 탑뷰 접기 편집기를 사용합니다. 15×15cm 기본 색종이(80g/m², 1.8g)의
앞면은 주황색, 뒷면은 크림색입니다. 전체 층 또는 위쪽의 연결된 부분을 선택해 접고, 종이를 뒤집을 수 있습니다.

## 종이접기 조작

| 조작 | 동작 |
| --- | --- |
| `1` / 잡아끌기 버튼 | 가장자리나 꼭짓점을 잡아 끌기. 잡은 점과 목표점에서 접기선이 자동으로 정해집니다. |
| `2` / 선 긋기 버튼 | 커서 호버로 시작점 확인 → 드래그로 직선 지정 → 가장자리를 잡고 선 반대편으로 끌기 |
| Shift 홀드 | 잡는 지점·접는 목표점·접기선의 스냅을 일시 해제 |
| `3` / 위쪽 연결부 | 전체 층 접기와 위쪽에서 잡은 연결부 접기를 전환. 이어진 면은 함께 움직입니다. |
| F / 뒤집기 버튼 | 종이를 좌우로 뒤집어 반대쪽 면과 층을 노출 |
| U / 펼치기 버튼 | 마지막 접기를 애니메이션으로 펼치기. 반복하면 정사각형까지 복원 |
| V / 관찰 보기 | 탑뷰와 비스듬한 관찰 시점 전환. 관찰 중에는 새 접기 금지 |
| Space / 일시 정지 | 접기 확정·펼치기·뒤집기 애니메이션 정지 및 재생 |
| 느리게 | 애니메이션을 0.2배속으로 재생. 진행 중에도 변경 가능 |
| C / 확정 토글 | 추가 클릭으로 확정하거나 마우스를 놓으면 바로 확정하도록 비교 |
| 좌클릭 | 추가 확정 모드에서 미리보기 종이를 클릭해 확정 |
| 우클릭 / `Esc` | 현재 접기나 접기선 취소 |
| `Z` / 되돌리기 버튼 | 미확정 작업 취소, 작업이 없으면 직전 접기 복원 |
| R / 새 종이 버튼 | 네 용지를 비교한 뒤 시작 확정 · 취소는 현재 작업 유지 |
| `G` / 비행기 가이드 | 기본 종이비행기 참고 가이드 표시. 이전/다음으로 단계 변경 |

기본값은 잡아끌기·전체 층·놓으면 즉시 확정입니다. 추가 클릭 확정은 비교용 옵션으로 남겨두었습니다. 접는 도중에는 모드와 확정 방식을
바꿀 수 없습니다. 선 모드에서는 잡은 부분을 선 너머로 충분히 넘기지 않고 놓으면
접기를 취소하고 선을 유지합니다. 꼭짓점과 각 변의 중간 지점은 기존 10px에서 28px 범위로 스냅을 강화했습니다. Shift를 누르거나 놓으면 드래그 중에도 즉시 스냅이 해제되거나 복원됩니다.
선 긋기 모드에서는 클릭 전에도 원형 시작점 표시가 나타납니다. 스냅된 후보는 큰 원으로 표시하며, Shift를 누르면 표시와 실제 시작점이 함께 자유 위치로 바뀝니다. UI 위에서는 표시하지 않습니다.
가운데 점과 가로·세로 중심선도 표시하고 스냅합니다. 중심선 가까이에서는 선 방향의
자유로운 이동을 유지하면서 선에 맞춥니다. 이 기준은 현재 외곽의 중앙이 아니라
원래 색종이의 재료 좌표를 따르므로 접고 뒤집어도 일관됩니다. 잡는 시작점은 실제
선택한 가장자리 위에 유지하며, 목표 위치와 선 그리기에 중심 기준을 사용합니다.
Shift로 중심 기준을 포함한 모든 보조 스냅을 해제할 수 있습니다.
접는 도중 창 포커스를 잃으면 드래그가 취소됩니다.

양쪽을 따로 접으려면 먼저 전체 층으로 몸통을 접고, `3`으로 위쪽 연결부를 선택해
한쪽을 접습니다. `F`로 뒤집은 뒤 반대쪽을 접습니다. 뒤집기도 `Z`로 되돌릴 수 있으며
접은 횟수에는 포함하지 않습니다. 접거나 뒤집는 중에는 층 선택을 바꿀 수 없습니다.
펼치기는 접기 기록을 한 단계씩 역재생합니다. 마지막 접기 뒤에 뒤집은 기록이 있으면,
먼저 그 뒤집기를 되돌린 다음 펼칩니다. `Z`는 애니메이션 없이 직전 작업을 복원하고,
R로 새 종이 선택을 열고 시작을 확정하면 현재 접기 이력을 초기화합니다. 실행 중 완료 비행 기록은 이전 기체 기록으로 남깁니다. 현재 펼치기는 기록 복원 방식이므로 새 접기선 자국을
남긴 채 자유롭게 여닫는 기능은 아닙니다.

오류를 관찰하려면 느리게를 켜고 `U` 또는 `F`를 누른 뒤, `Space`로 멈추고 `V`로
옆에서 봅니다. 진행 각도가 화면에 표시됩니다. 멈춘 상태에서도 관찰 시점과 속도를
바꿀 수 있습니다. `Esc` 또는 우클릭은 진행 중 애니메이션을 취소하고 시작 상태를
복원합니다. 펼치기와 뒤집기는 종이 연결 정보도 함께 복원합니다.

위쪽 연결부 모드에서는 마우스를 올린 가장자리의 시작 면을 표시합니다. 실제로 접을 때는 종이가 찢어지지 않도록 접기선 밖에서 이어진 면도 함께 움직입니다. 원래 종이에서 연결되지 않은 층도 선택한 부분 위를 가로막고 있다면 함께 들어 올립니다. 아래층이 고정된 위층을 뚫고 올라가도록 허용하지 않습니다.

이 단계는 조작감을 비교하는 기하 기반 프로토타입입니다. 각 면은 원래 색종이의
좌표와 연결선 정보를 보존합니다. 접기선 위의 연결선은 경첩으로 남고, 그 밖에서
이어진 면은 함께 회전합니다. 또한 들리는 부분을 덮는 윗층도 포함하고, 새로 포함된 면의 연결과 윗층을 반복해서 확인합니다. 뒤집기와 되돌리기도 원래 종이의 연결을 유지합니다.
단순한 면적 보존뿐 아니라, 연결선 양쪽 위치와 한 장으로 이어져 있는지도 검증합니다.

각 접기는 완전히 평평하게 확정합니다. 휘어짐, 종이층 사이 충돌과 두께,
벌리기·뒤집어 넣기 같은 복합 접기는 아직 구현하지 않았습니다.
따라서 종이의 연결은 보존하지만 모든 물리적 종이접기 제약을 재현하지는 않습니다.
날개 펼침과 첫 비행 시험은 B에서 제공합니다. 게임 진행 저장과 비행 계수 보정은 아직 없습니다.
면이 2,048개를 넘는 추가 접기는 제한합니다.

## 기본 종이비행기 가이드

새 종이에서 `G`를 눌러 참고 가이드를 열고 이전/다음으로 단계를 넘깁니다.
노란 점선은 접기선, 빈 원은 잡는 위치, 채워진 점은 옮길 목표 위치입니다.
가이드는 조작을 제한하거나 자동으로 종이를 접지 않습니다.

1. 세로 중심선을 기준으로 반 접기
2. 다시 펼쳐 중심 기준 확인
3. 왼쪽 위 모서리를 가운데로 접기
4. 오른쪽 위 모서리도 가운데로 접기
5. 왼쪽의 비스듬한 변을 중심선에 맞춰 코 좁히기
6. 오른쪽도 같은 방식으로 접기
7. 전체 층을 세로 중심선으로 접어 몸통 만들기
8. 위쪽 연결부 모드에서 첫 번째 날개 접기
9. 종이 뒤집기
10. 반대쪽 날개 접기

정사각형 색종이로 만든 평평한 기본형까지가 현재 검증 범위입니다.
기본형을 만든 뒤 B에서 날개를 벌려 비행을 시험할 수 있습니다.
화면 가이드와 기능 검사는 `scripts/airplane_guide.gd`의 같은 순서를 사용합니다.
검사는 매 단계의 연결·면적·층 관통 여부를 확인하고 양쪽 날개까지 완주합니다.

## 날개 각도와 첫 비행 테스트

`B` 또는 날기 테스트 버튼으로 현재 접은 종이를 준비 화면에 가져갑니다.
확정한 비행 부위가 있으면 해당 두 접기 축과 손잡이 기준을 사용합니다. 미지정이면
마지막 두 `위쪽 연결부` 접기를 추천 후보로 사용하며, 실제 기록을 3D로 다시 계산해 펼칩니다. 날개 기록이 없는 종이도 발사할 수 있지만 각도 조절은 비활성화됩니다.
펼친 이음새의 연결이 유지되는지 확인하며, 보존하지 못하면 비행 준비를 중단합니다.
원래 편집 데이터는 변경하지 않습니다.
기본 자세는 90°로 펼친 날개 면을 수평으로 맞추고, 남은 몸통(손잡이)이 아래를 향하게 합니다.
이 기준은 이후 날개 각도를 조절해도 유지되며, 사용자가 직접 회전한 자세를 덮어쓰지 않습니다.

- **자세/날개 조정**을 열면 X/Y/Z 입력·회전 링과 날개 조절이 나타납니다. 닫으면 링도 숨깁니다.
- 날개 슬라이더: 날개 벌림 0–150°. 0°는 접힌 상태, 90°는 몸통과 직각입니다.
- 양쪽 함께 조절을 끄면 비대칭 각도를 비교할 수 있습니다.
- 빨강 X·초록 Y·파랑 Z 회전 링을 드래그: 선택한 월드축만 회전합니다. Shift를 누르면 15° 단위로 스냅합니다.
- X/Y/Z 각도 입력칸: 기체의 오일러 각도를 0.1° 단위로 입력합니다.
- 일반 드래그는 동체 자세를 바꾸지 않습니다. 자세는 축별 회전 링과 숫자 입력으로 조절합니다.
- 우클릭 드래그: 기체를 중심으로 카메라 시점 회전. 휠 위/아래: 확대/축소. 비행 중에도 사용할 수 있고, 재시도 시 시점 설정을 유지합니다.
- 발사 좌우 방향은 정면 0° 고정이며 별도 방향 UI는 없습니다. 기체 자체 X/Y/Z 회전은 발사 방향과 독립입니다.
- 기체 자세 초기화: 기본 자세로 되돌립니다. 기수 방향은 직접 판단해 화살표에 맞춥니다.
- 준비 중 ↑/↓로 목표 고도각(-80–80°)을 1°씩 직접 조절합니다. 게이지가 움직이는 동안과 비행 중에는 목표를 고정합니다.
- Enter/Space 또는 하단 버튼: 첫 입력으로 왕복 강도 게이지 시작 → 둘째 입력으로 강도(1–100%) 확정 → 커서가 끝까지 진행하고 돌아오면 셋째 입력으로 원점 영역에 맞춰 발사합니다.
- 원점 0의 전체 20px 영역 안이면 목표 고도각으로 발사합니다. 영역 오른쪽에서 일찍 누르면 위쪽, 영역 왼쪽에서 늦게 누르면 아래쪽으로, 영역 경계에서 벗어난 거리에 비례한 고도각 편차를 적용합니다. 좌우 편차·랜덤 오차·강도 보너스는 없습니다.
- 올라가는 동안에는 발사할 수 없으며, 파워를 이미 돌아오는 중에 골랐다면 그대로 복귀합니다. 입력하지 않고 늦은 쪽 끝까지 지나가면 확정한 강도로 빗맞은 상태를 자동 발사합니다. 진행 중 자세와 날개는 잠깁니다. Esc/취소는 자동 발사까지 취소하고 이전 준비 값으로 돌아갑니다.
- R: 자세·고도각·힘·날개 각도를 유지하며 발사 위치로 돌아갑니다. B: 접기로 돌아갑니다. Esc는 열린 결과/조정 영역 또는 게이지부터 닫고, 다음 입력에서 접기로 돌아갑니다.
- 1m 격자와 궤적, 수평 이동 거리, 첫 지면 접촉까지의 체공시간을 표시합니다.
- 오른쪽 **결과**에서 강도·목표/실제 고도각·편차·자동 빗맞음 여부·거리·체공시간·날개 각도와 종료 이유를 스크롤해 읽습니다. 비행 중에도 열 수 있으며 새 결과가 창을 자동으로 열지는 않습니다. 기록은 해당 화면에서만 유지합니다.
- 오른쪽 아래 **랜덤** 버튼은 수평 방향과 풍속(0.5–3.0m/s)을 무작위로 설정하고, 별도 **리셋** 버튼은 무풍(0m/s)으로 돌립니다. 바람 UI는 이전의 1.5배 크기이며 화살표는 현재 카메라에서 바라본 바람의 이동 방향입니다. 카메라의 방향이 바뀌면 표시도 함께 회전합니다. 카메라 기준 X·Y·Z 전체 성분으로 3D 자세를 맞추므로 카메라를 향하거나 멀어지는 깊이 방향도 표현합니다. 넓고 납작한 3D 화살표는 길이축을 중심으로 자체 회전하며, 풍속 1m/s당 초당 0.5회전합니다. 무풍에서는 회전을 멈추고 중립 점을 표시합니다.
- 바람은 실제 공기력 계산에 반영합니다. 준비 중에만 변경할 수 있고 게이지/비행 중에는 고정됩니다. 재시도는 선택한 바람을 유지합니다. 각 결과와 덤프에 실제 사용한 바람 벡터/풍속을 기록합니다.
- Ctrl+Shift+D 덤프에는 날개 각도, 발사 자세·방향·힘·초기 속도, 실제 3D 형상, 속도·각속도·궤적·비교 결과도 포함합니다.

현재 모델은 선택한 용지의 실제 크기와 평량(45/80/120g/m²), 공기 밀도 1.2kg/m³를 사용합니다. 새 비행은 지면 위 **1.7m, 기체 무게중심 기준**에서 시작합니다.
질량과 무게중심은 모든 재료 면에서 계산하고, 공기력 면적은 같은 평면의 중첩 부분을
제거해 겹친 종이층 수만큼 양력이 늘지 않도록 합니다. 면별 양력·항력과 회전 속도를
고려한 힘을 Jolt 강체에 적용합니다. 충돌 형상은 얇은 볼록 껍질 근사입니다.

[Li 외(2022), JFM 937 A6](https://doi.org/10.1017/jfm.2022.89)의
받음각별 양력·항력 계수와 압력중심 이동, 회전 양력·회전 항력식을 참고합니다.
작은 삼각형 분할마다 힘을 따로 적용하지 않고 같은 평면의 노출 면을 묶어,
날개 형상의 평균 시위와 압력 작용점을 계산합니다. 물리 계산은 240Hz이며
질량중심 주위 관성은 재료 삼각형을 면적으로 적분합니다.
게임에서는 형태·기체 자세·발사각·던지기 힘에 따른 비행 차이가 일관되게 작동하는 것을 우선합니다.
힘은 초기 속도에 대응하며 50%는 4.08m/s, 80%는 6.528m/s, 100%는 8.16m/s입니다.
중력은 기본 배율 1.0이며 중력·공기력의 0.05 배율은 제거했습니다.
기체의 초기 기준 프레임은 양쪽 날개 90°의 주 날개 면을 기준으로 정하고,
이후 날개 각도 변경에는 같은 프레임을 유지합니다. 발사 자세와 발사 방향은 계속 독립적입니다.
20m·3초를 강제하지 않으며 형태·자세·발사각·힘에 따라 결과가 달라집니다.
강하게 던져도 기체가 불안정하면 거리가 줄 수 있습니다.
현재 목적은 조작 흐름과 변수에 따른 차이를 검증하는 것이며 실제 비행거리
예측기가 아닙니다. 종이의 탄성·공력 탄성·돌풍·고급 유동 해석은 포함하지 않습니다. 바람은 한 번의 비행 동안 일정한 수평 상대풍으로 계산합니다.

기능 검사는 기본 비행기를 접은 뒤 서로 다른 날개 각도의 3D 연결·면적 보존,
질량과 노출 면적, 고정 발사·착지·체공시간, 동일 설정 재실행, 편집 상태 복귀를 검사합니다.

논문 평판 대조군은 `tests/test_flight_research.gd`로 별도 실행합니다.
조건·재현 범위·생략한 항과 결과 파일은 [연구 모델 검증](docs/reviews/flight-research-2026-10-25.md)에 정리합니다.

## 개발 기준

- 월드 단위는 1 unit = 1m, 위쪽은 +Y, 전방은 -Z입니다. 바닥 윗면은 Y=0입니다.
- 종이 크기는 m, 질량은 kg 기준으로 작성합니다.
- 3D 물리 레이어 1은 `World`, 2는 `Paper`입니다. 종이 물체에는 레이어 2와
  마스크 1을 지정합니다. 종이끼리 충돌이 필요하면 마스크 2도 추가합니다.
- 물리 이동과 힘 계산은 `_physics_process()`에서 처리합니다.
  순간이동 직후에는 `reset_physics_interpolation()`으로 보간 이력을 초기화합니다.
- 씬은 `scenes/`에 보관합니다. 스크립트와 에셋 폴더는 실제 파일이 생길 때 추가합니다.
- 프로토타입은 GDScript를 사용합니다. C# 도입 시 Godot 버전에 맞는 .NET SDK를
  확인하고 프로젝트 파일을 생성합니다.
- 프로토타입 입력은 마우스와 물리 키 코드로 처리합니다. 키 재지정이 필요해지면 Input Map 액션으로 옮깁니다.
- 도면과 덤프는 user://에 저장하며 웹 내보내기는 설정돼 있습니다. Steam SDK와 서버는 아직 연동하지 않았습니다.

그래픽은 로우폴리 미니게임을 지향합니다. 단순한 형태와 색상, 기본 조명을 사용하고
고사양 후처리보다 종이의 실루엣과 접힌 형태가 잘 읽히는 것을 우선합니다.
Compatibility 렌더러를 기준으로 대상 PC에서 호환성과 성능을 확인합니다.
Jolt는 충돌과 강체 운동을 담당합니다. 양력·항력과 종이 변형은 별도 구현 대상입니다.

## Git

기본 브랜치는 `main`입니다. `.godot/`, 내보낸 빌드, .NET 빌드 산출물은 제외하며,
Godot이 생성하는 `.uid` 및 `.import` 파일은 커밋합니다.
텍스트는 UTF-8과 LF를 사용합니다. 원격 저장소는 아직 연결하지 않았습니다.

덤프 단축키는 Godot 에디터의 실행 중지 키(F8)와 충돌하지 않도록 Ctrl+Shift+D를 사용합니다.

### 비행기 툰 표현

비행 화면의 종이는 3단계 음영과 주황색·크림색 양면, 진한 외곽선·면 경계선으로 표현합니다.
삼각형 분할 대각선은 숨기고, 접힌 층 순서를 펼친 면의 방향으로 옮긴 얇은 렌더 간격으로 겹친 면을 구분합니다.
별도 후처리 없이 종이 셰이더 한 패스로 처리합니다. 표시용 층 간격은 전체 0.6mm 이내이며 물리 형상·접기선·충돌·비행 계산에는 적용하지 않습니다.

### 종이접기 스냅 기준 편집

- `4` 또는 **기준 편집**을 누르고 **기준점**을 선택하면 클릭·드래그로 스냅 기준점을 옮깁니다.
- **기준선**을 선택하고 드래그하면 종이 끝까지 연장된 스냅 기준선을 만듭니다. 이 동작으로 종이를 접지는 않습니다.
- 지정을 마치면 원래 접기 조작으로 돌아갑니다. 기준점·선은 잡아끌기 목표 위치와 접기선 그리기의 스냅에 사용합니다.
- Shift 홀드로 스냅을 해제하고, 우클릭·Esc로 편집을 취소합니다. 취소하면 이전 기준을 유지합니다.
- **기본 중심으로**를 누르면 처음의 중심점·중심선으로 돌아갑니다. 새 종이는 사용자 기준을 초기화합니다.

사용자 기준은 원래 종이의 재료 좌표에 붙어서 접기·뒤집기·펼치기를 따라갑니다.
겹친 종이에 선을 지정하면 각 층에 기준을 남기므로, 펼쳤을 때 기준선이 여러 개로 나뉠 수 있습니다.
기준 정의와 화면에 표시된 위치, 편집 중 상태를 덤프에 포함합니다.
### 접기 작업 영역과 안내 (2026-10-24)

상단에는 접기 방식·연결부·뒤집기·되돌리기·펼치기·가이드·부위·내 도면과 도구 버튼을 둡니다. **날려보기**는 하단의 고정된 강조 버튼입니다.
기준 편집·옆에서 보기·일시 정지·느리게·확정 비교·덤프는 **도구…**에서 열며 기존 단축키도 그대로 사용할 수 있습니다.
덤프 저장 성공·실패 알림은 도구를 닫은 상태에서도 하단에 표시합니다.

접기 화면은 실제 창 크기의 글자와 버튼을 사용하고, 상·하단 UI와 가이드 패널을 제외한 작업 영역에 종이를 맞춥니다.
가이드가 켜져 있으면 노란 원에서 목표점으로 향하는 화살표와 조작 방식별 설명을 보여 주고, 안내 위치도 일반적인 스냅 후보에 포함합니다.
스냅 후보는 가이드가 켜져 있을 때만 추가되며 Shift로 해제할 수 있습니다. 다른 위치를 자유롭게 접는 동작을 제한하지 않습니다.

드래그·접기선 그리기·기준 편집 도중에는 카메라 맞춤을 고정합니다. 창 크기가 바뀌어 진행 중 조작의 좌표를 유지할 수 없으면 종이를 보존하며 취소하고 다시 잡도록 알립니다.
접는 동안 함께 움직이는 면을 민트색으로 강조합니다. 충분히 넘기면 커서 둘레가 초록색으로 바뀌고 ‘놓으면 확정’ 안내가 나타납니다.
각도가 부족해 놓으면 취소되는 경우 다음 행동을 알려 주며, 추가 확인 클릭은 요구하지 않습니다.

마지막 가이드에서는 하단의 **날려보기 [B]**를 안내합니다. 단계는 수동으로 넘기며 10/10을 실제 완성 판정으로 사용하지 않습니다.
비행 준비와 접기는 모두 실제 창 크기에 맞추며, 640×360에서도 조정·결과 목록을 스크롤할 수 있습니다.
640×360에서는 긴 가이드 설명을 스크롤해서 읽을 수 있습니다.

상세 검증과 스크린샷 위치는 `docs/reviews/folding-ux-2026-10-24.md`에 정리합니다.

### 펼친 종이층의 앞뒷면 표시 (2026-10-25)

비행 준비에서는 최종 접힌 면 순서와 각 면의 접힌 방향을 함께 보존합니다.
날개를 펼치거나 기체를 뒤집으면 그에 따라 표시용 층 간격도 회전하므로, 양면 색과 접힌 면 경계를 유지하면서 실제 바깥쪽 면을 그립니다.
카메라 깊이에 면 번호를 일괄 더하던 방식은 사용하지 않습니다. 물리 정점과 날개 형태를 대칭으로 맞추는 보정은 하지 않습니다.
기존 덤프 2종과 비대칭 색 문제가 보고된 덤프에서 위·아래·뒤집힌 시점의 GPU 픽셀 색을 표면 판정과 비교합니다.
동일 형상·시점의 전후 PNG와 검사 결과는 `docs/reviews/wing-surface-2026-10-25.md`를 참고하세요.

### 내 도면 (종이 도면 저장)

접기 화면에서 **내 도면 [P]**를 열고 이름을 입력한 뒤 **현재 도면 저장**을 누릅니다.
목록에서 도면을 선택하고 **선택 도면 불러오기**를 누르면 현재 종이를 바꾸기 전에 확인합니다.
같은 이름으로 저장할 때도 덮어쓰기 확인을 거칩니다. 취소하면 기존 파일과 현재 종이를 유지합니다.

종이 모양·접기/뒤집기 이력·접은 횟수·사용자 기준점/선·확정한 비행 부위·용지 종류/실제 치수/평량을 함께 저장합니다.
불러온 뒤에도 되돌리기, 펼치기, 추가 접기와 날려보기를 이어갈 수 있습니다.
발사 자세·힘·날개 펼침 각도·비행 기록은 이 프리셋에 포함하지 않습니다.

파일은 `user://presets/`에 저장하며, Windows 기본 경로는
`%APPDATA%\Godot\app_userdata\Paper AirPlane\presets`입니다.
이름은 파일 안에 보관하고 파일명은 이름의 해시를 사용합니다. 앱을 다시 실행해도 목록을 읽습니다.
좌표 정밀도를 보존하는 JSON 형식이며 임시 파일을 쓴 뒤 교체합니다.
손상되거나 지원하지 않는 형식은 오류를 표시하고 현재 작업을 유지합니다.
현재는 로컬 저장만 지원하며 삭제·이름 변경·미리보기·클라우드 동기화는 제공하지 않습니다.
### 브라우저 테스트 빌드 / GitHub Pages

테스트 주소: https://djejsGames.github.io/PAP/ (첫 배포 성공 후 활성화)

`main` 푸시 또는 Actions의 **Web test build → Run workflow**로 빌드합니다.
일반 Godot 4.7.1과 같은 버전의 공식 웹 템플릿을 사용하며, 헤드리스 회귀 검사와
웹 내보내기가 성공한 결과만 GitHub Pages에 배포합니다. 저장소의 Pages 소스는 **GitHub Actions**입니다.
빌드 결과는 Actions의 Pages 아티팩트로 올리며 소스 브랜치에 커밋하지 않습니다.

로컬에서는 일반 Godot 4.7.1에서 `Web` 내보내기를 실행합니다.
`build/web/index.html`을 생성한 뒤 HTTP 서버로 제공해야 합니다. 파일을 직접 더블클릭하지 않습니다.
예: 프로젝트 루트에서 `python -m http.server 8000 --directory build/web` 실행 후 `http://localhost:8000` 접속.
Mono 에디터는 웹 내보내기를 지원하지 않습니다. 기존 데스크톱 개발에는 계속 사용할 수 있습니다.

웹은 Compatibility / WebGL 2 / 싱글 스레드 빌드입니다. PWA 캐시는 사용하지 않습니다.
한글 표시를 위해 웹에서만 Nanum Gothic을 사용하며 OFL 라이선스는 `assets/fonts/OFL.txt`에 있습니다.
덤프 버튼은 JSON 다운로드를 요청합니다. 프리셋은 브라우저의 IndexedDB에 저장되므로
데스크톱 저장본과 별개이며, 사이트 데이터 삭제·시크릿 모드·저장소 차단 시 유지되지 않을 수 있습니다.
현재 조작은 마우스와 키보드를 기준으로 하며 태블릿 터치 전용 조작은 별도 구현하지 않았습니다.


### 비행 부위 지정

접기 화면의 **비행 부위** 버튼에서 기존 접기 기록을 날개 1·2로 선택하고 손잡이 기준 면을 고릅니다.
민트 날개 1 / 노랑 날개 2 / 보라 손잡이는 이름과 외곽선을 함께 표시합니다.
각 부위의 **강조 보기**로 현재 추천을 바꾸지 않고 아래에 가려진 층까지 확인할 수 있습니다.
날개 1·날개 2·손잡이 역할을 눌러 후보와 강조를 확인합니다. 90° 펼침 미리보기에서 선택한 축·손잡이 아래 기준을 확인한 뒤 **확정하고 날려보기**로 바로 비행 준비에 들어갑니다. **확정하고 계속 접기**와 미확정 상태의 **계속 접기**도 제공합니다.
새 접기선이나 잘라낸 부위는 만들지 않으며, 연결을 보존하지 못하는 조합은 확정하지 않습니다.

접기 이력과 종이 상태의 서명으로 지정을 검증합니다. 추가 접기·뒤집기·펼치기·되돌리기 등으로
상태가 달라지면 **재확인**을 표시하고 자동 추천으로 돌아갑니다. 원래 상태가 정확히 복원되면 기존 지정이 다시 유효합니다.
새 종이는 지정을 지웁니다. 프리셋/덤프는 지정을 포함하며 예전 프리셋은 미확정 추천으로 불러옵니다.
미확정 상태에서도 기존 자유 비행은 가능합니다. 고르기 어려운 접기 축은 번호 목록으로 선택합니다.

표시명은 Paper Airplane Park로 바뀌었지만 Windows의 기존 `Godot/app_userdata/Paper AirPlane`과
웹의 기존 `godot/app_userdata/Paper AirPlane` 경로를 유지하여 프리셋·덤프를 옮기지 않습니다.

### 공력 작용점 수정 (2026-10-26)

압력중심의 국소 속도로 기본 공력을 계산하고 같은 위치의 토크를 적용합니다. 회전 양력도 계산한 면 중심에서 작용하는 토크를 포함합니다. 접선 흐름이 없는 순수 회전에서는 면의 앞뒤 방향에 따라 압력중심이 바뀌지 않도록 기준 방향을 고정했습니다.

강한 감쇠나 추가 회전 상한은 사용하지 않았습니다. 물리 계산은 240Hz를 유지합니다. 덤프 재현과 비대칭 날개, 무풍·역풍·횡풍을 240/480/960Hz에서 검증하며 자동 배포 전에도 검사합니다. 시간 간격에 따른 궤적 차이는 아직 남아 있습니다. 자세한 결과는 [검증 기록](docs/reviews/force-points-2026-10-26.md)을 참고하세요.

### 반복 플레이 흐름 (2026-10-26)

접기와 비행 하단의 민트색 버튼은 같은 위치에서 다음 행동을 안내합니다. 날려보기 → 던지기 준비 → 강도 결정 → 끝점까지 진행 대기 → 원점에서 던지기 → 비행 중 → 다시 던지기로 연결됩니다. 착지 뒤 **다시 던지기** 한 번으로 위치 복귀와 새 강도 게이지를 시작합니다. 실제 발사는 기존 원점 입력으로만 진행합니다. **발사 위치로 [R]**는 게이지를 시작하지 않는 보조 기능입니다.

착지 직후 거리·체공시간을 하단에 표시하고, 상세 결과는 사용자가 엽니다. 결과창은 거리·체공을 먼저 보여 주며 **다시 던지기**와 **접기 수정**으로 이어집니다. 게이지 중에는 결과 버튼을 잠가 준비가 조용히 취소되는 일을 막습니다.

비행에서 접기나 부위 확인을 거쳐 돌아와도 목표 고도각·바람·마지막 준비 강도·카메라·줌·완료 기록을 유지합니다. 같은 형상과 같은 부위 지정에서는 수동 자세·날개도 유지합니다. 형상이나 지정이 바뀌면 자세·날개 기본값 복귀를 하단에 알리고, 예전 형상의 기록에는 **기체 수정 전**을 표시합니다. 진행 중 게이지는 취소하며 자동 발사 예약은 복원하지 않습니다. 이 보존은 앱 실행 중에만 적용합니다.

내 도면 저장 성공은 창을 닫고 비차단 알림으로 전달하므로 곧바로 접기를 이어가거나 하단 날려보기를 누를 수 있습니다. 내 도면 창에도 계속 접기·날려보기 출구가 있으며 덮어쓰기·불러오기 확인은 유지합니다. 부위 확정과 저장은 비행의 필수 단계가 아닙니다.

검증과 두 해상도 연속 화면은 [반복 플레이 구현 기록](docs/reviews/play-flow-implementation-2026-10-26.md)을 참고하세요.

### 용지 선택과 호환 (2026-10-26)

독립 실험실(main.tscn)은 선택 창 없이 기본 색종이를 제공합니다. 공원은 상점 구매로 시작합니다. 상단의 현재 용지 요약 옆 **새 종이 [R]**에서 네 카드를 비교합니다. 클릭은 후보만 바꾸며 **이 종이로 시작**에서만 현재 접기를 교체합니다. 취소/Esc는 현재 종이·준비한 접기선·이력·부위·비행 맥락을 유지합니다. **저장하고 시작**은 기존 내 도면 저장을 거치고, 취소나 실패 시 새 종이를 만들지 않습니다. 발사와 재시도마다 용지를 다시 선택하지 않습니다.

| 용지 | 크기 | 평량 | 한 장 질량 |
|---|---|---|---|
| 색종이 | 15×15cm | 80g/m² | 1.8g |
| A4 복사용지 | 21×29.7cm | 80g/m² | 4.9896g |
| 신문지 (국내 대판 한 면) | 39.1×54.5cm | 45g/m² | 9.589275g |
| 4절 도화지 (사륙) | 39.4×54.5cm | 120g/m² | 25.7676g |

화면의 질량은 소수 둘째 자리까지 표시합니다. 평량은 실제 질량과 관성에, 크기는 실제 기하·면적·무게중심·관성에 반영합니다. 색면·흰 직사각형·자체 생성 인쇄 패턴·옅은 질감으로 구분하며 거리 보너스나 강성/휘어짐 차이는 추가하지 않았습니다. 정사각형은 크기에 맞는 기존 가이드를 사용하고, A4·신문지·4절 도화지는 정사각형 가이드라는 안내와 함께 원래 비율로 자유롭게 접습니다.

기존 20cm 도면은 **이전 도면 · 20×20cm**로 원래 재료 좌표와 80g/m²를 유지합니다. 20cm를 새 선택지로 추가하거나 15cm로 축소하지 않습니다. 메타데이터 없는 예전 도면은 치수를 재료 좌표에서 읽습니다. 새 메타데이터는 도면·덤프·발사 결과에 보존하며 이후 종이 교체가 과거 조건을 바꾸지 않습니다. 과거 재현 덤프의 1.5m 발사도 저장된 높이 그대로 재현합니다.

두 해상도 화면과 물성·호환·웹 검증은 [용지 구현 기록](docs/reviews/paper-stock-implementation-2026-10-26.md)을 참고하세요.

### 선 긋기 15° 스냅과 용지 규격 변경 (2026-10-26)

2번 선 긋기에서는 시작점을 기준으로 15° 간격에 방향을 맞춥니다. 꼭짓점·변 중앙·기준점·기준선·가이드에 맞춘 끝점은 우선 보존하여 22.5° 등 정확한 정렬도 유지합니다. Shift를 누르면 위치와 각도 스냅을 함께 해제하고, 놓으면 원래 커서 위치에서 다시 스냅합니다. 잡아끌기와 비행 자세 회전에는 이 변경을 적용하지 않습니다.

새 도화지는 사륙 4절39.4×54.5cm, 새 신문지는 국내 대표 대판 한 면39.1×54.5cm를 사용합니다. 평량은 120/45g/m²를 유지합니다. 기존15cm 신문지·도화지 도면/기록은 실제 크기와 질량을 유지하며 새 선택만 새 규격을 씁니다. 큰 종이의 카드 샘플과 비행 준비 카메라도 실제 크기에 맞춥니다. [규격 근거·검증](docs/reviews/line-angle-paper-sizes-2026-10-26.md).
