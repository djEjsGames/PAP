# 공원 조작 후속 수정 — 2026-10-27

이동 계산은 유지하고 캐릭터 회전을 같은 카메라 기준 이동 방향에 연결했다. 정지하면 마지막 방향을 유지한다. 벽에 막히거나 미끄러질 때는 입력 의도를 바라본다. 일반 운반의 손 목표와 종이 자세도 몸 방향을 따른다. 카메라와 발사 조준은 기존 값을 사용한다.

발사 준비와 게이지 입력 중에는 캐릭터 외형만 숨긴다. 발사 또는 준비 취소 후 외형을 복원한다. 충돌체와 종이의 실제 발사 높이 1.7m는 유지한다.

착지하면 하단 주 버튼을 활성 ‘공원으로 돌아가기 [B / Esc]’로 바꿨다. 버튼 클릭은 관람을 종료하며, 종이를 자동 회수하지 않는다. 발사 후 게이지 트랙과 취소 버튼을 숨기고, 착지 후에는 거리·시간·회수 안내를 표시한다. Esc는 기존처럼 결과/자세 창을 먼저 닫는다.

검증:

- test_park_review.gd: 헤드리스 356개, GPU 356개 통과. 두 해상도에서 W/A/S/D, 카메라 yaw 0/90°, 정지 후 카메라 회전, 준비 숨김/취소 복원을 포함한다.
- test_park_controls.gd: 헤드리스 34개, GPU 34개 통과. 두 해상도에서 실제 물리 착지, 준비/게이지 숨김, 발사 후 복원, 활성 복귀 버튼, Esc 팝업 우선순위, 같은 월드 바디 유지와 자동 회수 방지를 확인했다.
- 640×360 준비 화면과 착지 화면 PNG를 직접 확인했다. 캡처는 build/previews/defaults_review_ready_origami_0_640.png 및 defaults_controls_landed_640.png에 있다.
