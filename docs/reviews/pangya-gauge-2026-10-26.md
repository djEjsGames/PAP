# 팡야식 발사 게이지 검토 — 2026-10-26

사용자 확정: ↑/↓로 목표 고도각을 직접 정하고, 왕복하는 강도를 고른 다음 원점 타이밍으로 고도각 정확도를 결정합니다. 끝까지 입력하지 않으면 빗맞은 상태로 자동 발사합니다.

## 조작과 실제 적용

1. 준비 중 ↑/↓로 목표 고도각을 1°씩 설정합니다. 기존 -80–80° 범위를 유지하고 발사 화살표에 반영합니다.
2. Enter/Space 또는 하단 버튼으로 강도 게이지를 시작합니다. 1–100%를 계속 왕복합니다.
3. 다시 입력하면 강도를 확정합니다. 금색 선은 확정 강도입니다. 올라가는 중에 확정해도 민트 커서는 끝점까지 계속 간 뒤 흰 원점 0을 향해 돌아옵니다. 이미 돌아오는 중에 확정했다면 그대로 복귀합니다. 올라가는 동안에는 최종 발사 입력을 받지 않습니다.
4. 마지막 입력으로 발사합니다. 원점 중심의 전체 20px(좌우 10px) 영역 안이면 목표 고도각으로 발사합니다. 영역보다 오른쪽의 이른 입력이면 위쪽, 영역보다 왼쪽의 늦은 입력이면 아래쪽으로 고도각 편차가 생깁니다.
5. 원점 왼쪽 끝까지 입력이 없으면 그 끝의 오차로 자동 발사하고 결과에 ‘자동 빗맞음’을 기록합니다.

고도각·자세·날개는 게이지 진행 중 고정합니다. Esc/취소는 예정된 자동 발사도 취소합니다.
재시도는 목표 고도각과 강도를 유지하고 타이밍 오차를 지웁니다. 키 홀드/중복 이벤트가 여러 단계를 넘기지 않게 하는 기존 처리는 유지합니다.

원점의 판정과 표시 모두 화면 전체 폭이 달라도 20px을 유지합니다. 영역 경계까지는 편차 0이며,
영역 밖에서는 경계에서 벗어난 거리에 비례합니다. 랜덤이 아니라 영역 밖 정규화 거리 × 30°입니다.
발사 시점의 영역 폭과 정규화 허용치를 저장하므로 이후 창 크기를 바꿔도 이미 발사한 각도는 바뀌지 않습니다.
늦은 쪽 끝은 -20%이며, 자동 빗맞음에도 같은 영역 경계 기준을 적용합니다.
극단적인 목표에서 뒤쪽으로 발사하지 않도록 실제 고도각은 -89–89°로 제한합니다.
목표와 실제 고도각, 실제 적용 편차를 각각 기록하므로 제한이 적용된 경우에도 기록이 실제 초기 속도와 일치합니다.
강도 왕복의 편도는 2.4초이며 돌아오는 커서는 강도 전체 폭의 초당 65% 속도인 첫 체감 조정값입니다.
강도는 기존 최대 8.16m/s 배율을 유지합니다. 타이밍 오차는 강도·좌우 방향·수동 기체 자세를 바꾸지 않습니다.

## 기록

비행 결과와 덤프에 `target_aim_degrees`(목표), `aim_degrees`(실제), `timing_error`(원점 거리),
`elevation_deviation`(실제 적용 편차), `automatic_miss`(자동 빗맞음), `origin_width_px`(영역 폭), `origin_tolerance`(발사 시 허용치), `origin_hit`(영역 안 판정)을 보존합니다.
기존 힘·초기 속도·날개 각도·거리·체공시간 등의 기록도 유지합니다.

## 검사

- GPU 화면/회귀 검사 13,263개 및 후속 초기화 검사까지 포함한 헤드리스 검사 12,569개, 실패 0건. 두 로그 모두 SCRIPT ERROR/ERROR 없음.
- 상하키와 고도각 한계, 강도 왕복, 확정 후 끝점 도달·복귀, 이미 복귀 중인 선택, 두 창 크기에서 정확한 20px 영역·양쪽 경계, 영역 밖 비례 편차, 강도/자세/좌우 보존, 자동 빗맞음 한 번 발사, 자동 발사 취소, 재시도, 결과/덤프 수치 일치를 검사했습니다.
- Edge/WebGL2에서 실제 상하키로 목표 6°를 지정하고 수동 타이밍 발사와 자동 빗맞음을 실행했습니다. 실제 발사 고도각·초기 속도·결과 기록의 일치를 확인했고 콘솔 오류는 없었습니다. 후속 20px 영역 검증에서는 확정 뒤 커서의 끝점 도달/복귀와 파워 고정을 확인했습니다. 목표 6°에서 자동 빗맞음의 실제 고도각은 약 0.53°였습니다. 기존 프리셋과 부위 지정·저장 흐름도 함께 통과했습니다.
