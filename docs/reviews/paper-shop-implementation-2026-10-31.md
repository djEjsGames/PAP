# 종이 상점 로컬 구현

2026-10-31. 무료 색종이를 제거하고 새 공원은100코인/빈 보관함으로 시작한다. 고정 발견 비행기는 유지한다. 추가 커밋·푸시·Pages배포는 하지 않았다.

## 사용

작업대 왼쪽 종이 상점에 가까이 가 E → 네 카드 비교 → 1장 구매 → 닫기/Esc → 작업대에서 E → 접기 마치고 보관 → Tab 꺼내기 → Space 투척 → E 회수. 시작 안내와 빈 보관함에도 상점 동선을 표시한다.

- 상점 SHOP=(-2.5,0,-2.5), 작업대 BENCH=(0,0,-2.5), 표적 시작선 PRACTICE_START=(4,0,1).
- park.coins=100, park.PRICES=[10,20,15,30]. 색종이/A4/신문지/4절 도화지 순서. 네 장 구매 후25코인.
- park.shop은 기존 paper_picker를 shop_mode=true로 재사용한다. shop.choose(index)는 비교만 한다. shop.start가 명시적인 구매 버튼이다.
- park.buy_paper(index)는 성공 시 유일 실물ID, 실패 시-1을 반환한다. 동기 검증→실물 생성→차감이며 잘못된 상품/부족 금액은 변경하지 않는다. 기본 Button의 놓기 1회에 한 장을 구매한다. 누름 유지/키 echo는 반복 구매하지 않고 별도의 다음 클릭은 즉시 한 장을 더 구매한다.
- 구매 후 selected_id를 새 종이로 설정한다. 작업대는 선택한 종이를 우선하며, 손에 있던 다른 기체의 ID·내용·소유 상태는 유지한다. owned_stock(index)는 알려진 실물 중 정리된 기체를 제외한다.
- shop.visible 동안 이동/투척/카메라/인벤토리/반복E를 차단한다. Esc는 상점만 닫는다. 발견물의 월드 마커도 상점 뒤로 숨긴다.
- 공원 편집기는 locked_stock을 최초 restore_sheet에서 기억한다. 새 재료 선택은 상점으로 안내하고, 다른 재료 reset/restore/preset은 거부한다. 거부 후 preset 확인 UI도 복구한다. finish_edit에서도 원래 재료와 대조한다. 같은 재료 접기 초기화/도면 적용은 허용하며 독립 main.tscn 실험실은 기존 무료 선택을 유지한다.
- 실물 ID/형상/이력/날개 설정은 보관→손→투척→회수에서 유지한다. 추가 비용은 없다. 공원 덤프에는 coins/shop_visible을 추가했다.

## 검증

새 tests/test_shop.gd는 초기 무료0/100코인, 실제 E 상점 입력, 선택/취소 무소비, 네 상품 가격·typed 빈 이력·유일ID, 잔액부족/0/잘못된 상품, 중복입력, 모달 차단, 재료 변경 우회/보관 거부/같은 재료 도면 재선택, 실제 물리 착지·회수, 기존 손 기체+신규 구매 선택, 정리된 기체 보유량 제외를 검사한다. 기존 공원 회귀는 숨은 무료 슬롯 없이 실제 구매 fixture로 갱신했다. CI에 새 상점 검사를 추가했다.

- headless 상점136개, 초기 꺼내기60, 공원182, 관찰360, 표적152, 입력38, HUD·오디오83, 접힘 겹침64, 소스 매핑1298, 전체 접기15662, 독립 흐름90, 기본값78, 용지438: 실패0.
- GPU 상점 두 해상도1280×720/640×360 렌더와 실제 투척 검사 통과. build/previews/defaults_shop_{start,compare,insufficient}_{1280,640}.png. 상점 위 발견물 안내 겹침을 제거했다.
- 상세 로그 build/shop*.log. 최종 headless/GPU 상점136개씩 통과. 실제 마우스 누름 유지/별도 두 번 클릭 및 휠 차단까지 포함한다. 최종 두 화면의 잔액 부족 안내도 잔액·상품·부족액을 함께 표시한다.

## 한계

잔액과 실물은 세션 범위이며 종료하면 초기화된다. 도면 저장은 기존대로 영구 파일이다. 가격은 플레이 확인용이고 성능 순위나 실제 가격이 아니다. 수입/판매/장바구니/상점NPC/경제 밸런스는 추가하지 않았다. 이번 상점 버전의 Web export·공개 배포는 진행하지 않았다. 독립 실입력 교차검증과 사용자 체감 판정은 별도다.
