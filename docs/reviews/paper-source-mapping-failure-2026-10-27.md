# 새 A4 덤프: 원본 층 탐색 실패에 따른 관통 오탐

검토일: 2026-10-27. 입력은 `pap_2026-10-27T19-59-16_67921230.json`이다. 제품 코드와 원본 파일은 변경하지 않았다.

## 결론

앞선 16:43 덤프 수정이 적용된 현재 버전에서도 새 덤프가 실패한다. 이번에는 접기선 경계의 가짜 겹침 면적보다 **정상적인 면의 원본 층을 찾지 못하는 오류**가 직접 원인이다. 출처 불명의 `-1`을 최하층처럼 비교하면서 7번째 접기의 정상적인 포개짐을 관통으로 오인한다.

앞선 수정의 `_boundary_separated()`가 매우 짧은 변을 근거로 실제 면적 겹침을 0으로 만드는 경우가 남아 있다. 해당 면은 **자기 자신과의 겹침도 0**이므로 단순한 사용자 접기 실수로 설명할 수 없다.

## 재현 결과

- A4 21×29.7cm, 80g/m², 접기 8회·뒤집기 1회, 최종 80면, IDLE.
- `tests/validate_dump.gd`: 실패. ‘7번째 접기에서 아래쪽 종이가 고정된 위쪽 종이를 관통합니다.’
- `Presets._validate_state()`: 같은 오류로 실패. 형상·이력 일치 및 메타데이터 검사를 지나 층 간섭 검사에서 거부된다.
- 최종 재료 면적 0.0623699938740013m². 연결성·재료 보존 오류는 보고되지 않았다.
- 관통 보고는 16건이며 **모두 moving_layer=-1**이다. 정상 층 번호로 판정한 관통 보고는 없다.
- 기존 `tests/test_overlap_validation.gd`는 **62개 모두 통과**한다. 현재 회귀 사례만으로 이번 결함을 잡지 못한다.

## 오류가 생기는 순서

1. 재료 좌표에 거의 중복된 두 점이 있다. `(0, -0.0435000061988831)`와 `(-1.24442207649622e-8, -0.0434999950230122)` 사이의 길이는 약 **1.6726e-8m**다.
2. `_boundary_separated()`의 짧은 변 제외 기준을 이 변이 통과한다. 이 변에서 모든 점의 외적이 불확실성 범위 안에 든다는 사실을 ‘면이 분리됐다’고 해석한다.
3. `overlap_area()`는 실제 클리핑 전에 0을 반환한다. 원래 층을 찾는 `_material_source()`도 이 함수를 사용하므로 원본 층이 존재하는데도 `-1`을 반환한다.
4. 7회차 `move[9]`는 실제로 `before[41]`의 일부다. 현재는 -1로 처리된다. 고정된 하부 층 0~7, 16~23을 이 면보다 위라고 잘못 판단해 16건의 관통을 만든다.
5. `layer_obstructions()`는 `source_s <= source_m` 비교에 -1을 그대로 넣는다. 출처 탐색 실패와 실제 층 관통이 구분되지 않는다.

이력 전체에서 원본 층 미확인은 4곳이다. 6회차 이동면, 7회차 이동면과 고정면, 8회차 고정면이다. 직접 오류를 발생시키는 위치는 7회차지만, 수정 범위는 그 한 쌍만의 예외 처리로 끝내면 안 된다.

## 독립 계산으로 확인한 근거

Python 배정밀도 볼록 다각형 교차로 원본 재료 좌표를 대조했다. 알려진 사각형 교차 면적과 경계 접촉 자체 검사 2건을 통과했다. 원래 꼭짓점을 그대로 사용한 계산에서도 다음 면적이 확인됐다.

| 위치 | 현재 원본 층 | 독립 계산 원본 층 | 해당 조각의 재료 면적(m²) |
|---|---:|---:|---:|
| 6회차 move[6] | -1 | 6 | 0.0010410470511661412 |
| 7회차 move[9] | -1 | 41 | 0.0003078451337824996 |
| 7회차 stay[41] | -1 | 41 | 0.0007332019135753968 |
| 8회차 stay[22] | -1 | 22 | 0.0007332019135753968 |

각 조각과 복원된 원본 면의 교차 면적은 조각 자체 면적과 일치한다. 진단 중 볼록 껍질 계산도 대조했으나 원래 꼭짓점 계산으로 동일 결과를 확인했으며, 사용자 데이터는 바꾸지 않았다.

특히 7회차 `before[41].paper`를 자기 자신과 비교하면:

- 현재 `Paper.area()`: 약 **0.00104104701313m²**.
- 현재 `Paper.overlap_area(face, face)`: **0m²**.
- 독립 계산: **0.0010410470511661412m²**.

원본 층을 독립적으로 복원하면 7회차 이동 층은 **32~47**이다. 이를 기준으로 고정 상부 면과 실제 위치 겹침을 다시 검사한 결과, 현재 차단 기준 `1e-10m²`를 넘는 관통은 **0건**이었다.

## 개발 수정 요청 기준

1. `_boundary_separated()`의 수치적으로 불확실한 짧은 변이 면 전체의 분리를 확정하지 않게 수정한다. 실제 겹침·경계 접촉·판정 불확실을 구분하고, 정상 면의 자기 교차 면적이 소실되지 않아야 한다. 특정 좌표나 이 덤프만의 예외 처리는 피한다.
2. `_material_source()` 탐색 실패를 최하층으로 취급하지 않는다. 출처 불명을 무조건 건너뛰어 통과시키는 것도 피한다. 출처를 안정적으로 복원하고, 정말 실패하면 매핑 오류로 구분한다.
3. 원본 파일·형상·이력·부위·용지를 고치지 않은 채 새 덤프의 Dump/Presets 검증, 저장 왕복과 공원 보관 흐름을 통과시킨다. 이번 이력의 4곳 모두에서 원본 층 매핑을 확인한다.
4. 이번 덤프와 문제 면의 자기 교차를 회귀에 추가한다. 작은 변 길이와 좌표 위치, 꼭짓점 순서, 포함된 조각을 변화시켜도 매핑이 유지되는지 확인한다.
5. 이전 16:43 덤프 통과와 `wing_layer_overlap.json` 실제 관통 거부를 유지한다. 공통 겹침 판정의 접기 계획·매핑·간섭 검증 경로를 함께 확인한다. 허용 면적 일괄 상향이나 검증 생략은 하지 않는다.
6. 검증 실패 시 편집 중인 종이·되돌리기 이력을 유지한다. 수정 전후 결과와 수행/미수행 검사를 보고한다.
