# 원본 종이 층 매핑 오탐 후속 수정

2026-10-27. 새 원본 `pap_2026-10-27T19-59-16_67921230.json`은 형상·이력·용지·비행 부위·기준점을 바꾸지 않고 Dump/Presets 검증과 공원 작업대 보관을 통과한다. 이전 수정에서 미세한 변을 신뢰할 수 있는 분리축으로 잘못 판단하던 결함을 보완했다.

## 변경한 판정

`scripts/paper_geometry.gd`:

- 변 길이에 대한 제외 상수를 늘리지 않았다. 각 변이 자기 다각형의 내부를 float32 좌표 불확실성보다 뚜렷하게 구분할 수 있는지 먼저 확인한다. 이 조건을 만족하는 변만 다른 면의 분리를 증명하거나 불안정한 중복 변을 대신하는 클리핑 경계로 사용한다. 자기 면 전체가 불확실성 범위에 있다는 사실을 분리 증거로 사용하지 않는다.
- 면 전체가 좌표 해상도 수준으로 얇으면 모든 변을 버리지 않고 원래 변들로 배정밀도 클리핑한다. 그렇지 않으면 교차 제약이 모두 사라져 가짜 겹침이 생길 수 있다. 교차 면적은 각 입력 면의 면적을 넘지 않도록 제한한다.
- `_material_source()`는 같은 재료 좌표면을 우선 찾고, 나머지는 배정밀도 교차 면적을 비교한다. 공간상의 경계 접촉을 0으로 취급하는 전처리를 원본 재료 찾기에 적용하지 않는다. 폭이 반올림 오차만큼 작은 조각도 실제 원본이 필요하기 때문이다. 이 처리는 저장 검증을 생략하는 것이 아니라 층 순서 비교에 필요한 출처를 복원한다.
- 기본 가이드가 만드는 극소 조각끼리의 경계는 기록된 접기선도 추가 분리축으로 사용한다. 양쪽 면이 접기선 반대편에 있다는 수치 증거를 확인하며, 면이 실제로 접기선을 가로질러 겹치면 관통 검사를 계속한다. 0 또는 비정상 분리축은 사용하지 않는다.
- `layer_obstructions()`는 매핑 실패 -1을 층 번호로 비교하지 않는다. 미확인 조각을 `kind=source_mapping` 오류로 반환하며, 정상 매핑된 쌍에 대해서는 기존 관통 검사를 계속한다. 출처 불명을 무조건 건너뛰어 통과시키지 않는다.

`scripts/paper_dump.gd`:

- 매핑 오류는 `historical_source_errors`, 실제 관통은 `historical_layer_obstructions`로 구분한다. 둘 중 하나라도 있으면 검증 실패다.
- 매핑 실패는 ‘7번째 접기에서 조각의 원본 종이 층을 확인할 수 없습니다.’처럼 접기 번호와 한국어 원인을 표시한다. 실제 관통 문구는 유지한다.

공통 호출 경로인 계획 생성의 위층 동반 이동, 재료 원본 찾기, 이력 간섭 검사를 모두 확인했다. MIN_OVERLAP_AREA=1e-10m²와 FLOAT32_RELATIVE_EPS=2^-23은 올리지 않았다. 이전 보고서의 ‘짧은 변 길이만으로 제외’ 설명보다 이 후속 판정을 우선한다.

## 범위와 한계

원본 데이터 정리·저장 검증 생략·전역 허용 면적 상향은 하지 않았다. 최근 준비 카메라의 정후방/기본 15° 설정, 비행 물리, 용지 크기, 캐릭터 UX는 변경하지 않았다. 커밋·푸시·배포 및 브라우저 실행은 수행하지 않았다.

기하 계산은 현재 직선 분할로 생성되는 볼록 종이 면을 전제로 한다. float32 좌표 해상도 수준의 경계는 수치적으로 모호하므로, 모든 극소 침범을 실물 수준으로 구분한다고 보장하지 않는다. 이번 원본과 변형·기존 회귀는 자동 검증했으며 사람의 장시간 플레이 평가는 남아 있다.
