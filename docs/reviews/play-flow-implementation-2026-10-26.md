# 반복 플레이 UX 구현·검증 — 2026-10-26

[기획 요구](play-flow-ux-2026-10-26.md)를 반영했습니다. 이번에는 물리·종이 접기·게이지 속도·20px 원점과 고도각 편차·자동 빗맞음 규칙을 바꾸지 않았습니다. 일반 드래그 기체 회전 금지, 축별 회전·숫자 입력, 우클릭 카메라·휠 줌, 바람 HUD의 크기·3차원 자세·자체 회전을 유지했습니다.

## 행동 연결

- 접기와 비행 하단에 같은 위치·민트색 강조의 주 행동을 배치했습니다. 상단의 날려보기와 마지막 가이드의 중복 버튼은 제거하고 가이드에는 하단 행동을 안내합니다. 자주 쓰는 접기 도구는 상단에 남았습니다.
- 준비/강도/끝점 대기/원점 입력/비행/착지에 따라 하단 라벨과 활성 상태가 바뀝니다. 끝점 대기는 돌아온 뒤 입력하라는 이유를 표시합니다. 주 버튼 위치는 라벨·저장 알림·상단 줄바꿈의 영향을 받지 않습니다.
- 착지의 다시 던지기는 한 입력으로 위치 복귀와 새 게이지 시작까지 연결합니다. 실제 투척은 최종 타이밍 입력 뒤에만 진행합니다. R은 별도 '발사 위치로' 보조 기능입니다.
- 부위 패널은 역할 3개 중 선택한 후보만 보이고 내용만 스크롤합니다. 확정하고 날려보기/확정하고 계속 접기/계속 접기는 고정 하단에 남습니다. 연결 검증·강조·90° 미리보기·번호·명시적 확정은 유지합니다. 미확정 자유 비행도 유지합니다.
- 결과는 거리·체공시간을 먼저 표시하고, 다시 던지기/접기 수정으로 바로 이어집니다. 게이지 중 결과 열기는 버튼과 콜백 양쪽에서 막고 이유를 툴팁으로 표시합니다. 일반 결과 키 입력이 뒤의 발사·R로 새지 않습니다.
- 사용자용 프리셋 이름을 '내 도면'으로 정리했습니다. 성공 시 창을 닫고 비차단 알림을 표시하며, 관리 창에도 계속 접기/날려보기 출구를 제공합니다. 덮어쓰기와 현재 종이 교체 확인·취소·손상 데이터 보호는 유지합니다.

## 실행 중 맥락

접기 화면의 단일 flight_session 사전에 발사 조건·카메라·완료 기록을 복사해 보관하고, 새 비행 인스턴스에서 복원합니다. 영구 기록·별도 관리 시스템은 추가하지 않았습니다.

같은 형상 서명과 부위 지정이면 자세·날개를 유지합니다. 변경되면 기존 부위 유효성 검사를 통과한 지정 또는 자동 추천을 사용하고 자세·날개는 기본값으로 돌아갑니다. 이 이유를 숨겨진 조정 패널뿐 아니라 하단에도 표시합니다. 완료 기록은 깊은 복사로 유지하며 기록된 형상 서명이 다르면 결과와 하단 직전 요약에 기체 수정 전을 표시합니다. 이전 조건을 현재 바람·각도 등으로 소급 덮어쓰지 않습니다.

게이지 도중 왕복은 기존 취소 정책처럼 시작 전 준비 강도를 보존하며 새 화면은 준비 상태입니다. 게이지 커서·키 잠금·자동 빗맞음 예약은 복원하지 않습니다. 진행 중 비행 자체는 복원하지 않고 완료된 기록만 유지합니다.

웹 실제 입력 검증에서 B가 접기로 돌아간 뒤 같은 이벤트로 비행을 다시 여는 누수를 발견했습니다. 접기와 비행 양쪽의 B 전환에서 입력을 소비하도록 수정하고 실제 키 이벤트 회귀 검사를 추가했습니다.

## 구현 후 디자인 검토와 한계

대표 행동을 매번 상단에서 재탐색할 필요가 줄었고, 부위 완료·결과·저장 후의 출구가 다음 단계와 연결됐습니다. 640×360의 부위 완료 버튼은 처음부터 보이며 저장 알림도 주 버튼을 밀어내지 않습니다. 결과는 사용자 요청 시 열고 기체 수정 후에는 이전 기록을 구분합니다.

작은 창의 접기 상단은 여전히 두 줄이며, 부위 패널이 접기 도구 일부를 덮습니다. 부위 선택 중에는 패널의 계속 접기로 빠져나온 뒤 접는 흐름입니다. 역할 3개 버튼의 첫 발견성, 게이지 안내 문구와 반복 플레이 속도는 실제 사용자 플레이로 판단해야 합니다. 결과 항목이 많으면 작은 창에서 스크롤합니다. 세션 맥락은 앱 종료 시 사라집니다. Safari·실제 태블릿 터치·인간 마우스 손맛은 검증하지 않았습니다. 커밋·푸시·공개 Pages 배포는 하지 않았습니다.
