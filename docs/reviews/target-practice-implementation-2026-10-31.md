# 표적 비행 개선본 — 사용자 검증 준비 완료

2026-10-31. 기존 실물 기체로 표적을 향해 던지고, 관찰하고, 한 가지를 바꿔 다시 시도하는 로컬 개선본이다. 프로젝트 루트의 project.godot을 Godot에서 열고 F5로 공원을 실행한다. 기존 실행 창은 종료 후 다시 시작해야 변경을 읽는다.

## 5분 검증 순서

1. ‘공원에서 발견한 비행기’ 옆으로 걸어가 **E → 보관하기**. 새 게임의 ‘내 색종이’는 미접지 종이이므로, 빠른 비행 평가에는 기존 발견 기체를 권한다. 본인 도면도 사용 가능하다.
2. **I → 발견 기체 선택 → 꺼내기**. 작업대 오른쪽의 밝은 시작선으로 걸어가 **T**로 참여한다. 선은 (4, 0, 1), 원의 중심은 정면 4m 앞 (4, −3)의 지면이다. 참여해도 기체나 플레이어를 이동·복제하지 않는다.
3. **Space로 준비**. 첫 참고값은 무풍·고도각 10°·힘 약60%·양 날개90°. 고도각은 ↑↓ / ±, 날개는 ‘자세·날개’에서 조절한다. 게이지는 기존처럼 시작→힘 선택→끝점 후 돌아오는 원점에서 발사의 3입력이다.
4. 첫 접촉의 성공 여부와 중심 오차를 본다. **초록 ○=표적 안, 주홍 X=밖, 하늘색 +=자유 투척**이다. 표식은 첫 접촉 위치에 남고 굴러가는 기체를 따라가지 않는다.
5. **B → 기체까지 걸어가 E → 시작선까지 걸어 돌아와 Space**. 내 기체는 같은 ID로 바로 손에 들어오므로 I 왕복이 필요 없다. 다른 기체를 들고 있었다면 그것은 안전하게 보관된다.
6. 2회차는 날개만90°→110° 등 한 가지를 바꿔본다. 3회차는 결과를 보고 다시 조절한다. **결과**에서 최근3회와 ‘바꾼 조건’을 보고 주황색 직전 궤적과 비교한다. 걷고 돌아온 발사 위치나 실제 게이지 힘도 달라졌다면 조건에 표시된다.
7. 자유 투척으로 돌아가려면 공원에서 **T**. 연습 참여 중이라도 시작선 1m 범위를 벗어나 던지면 자유 투척이며, 연습 성공으로 기록하지 않는다.

사용자가 평가할 질문과 체크박스는 [기획 플레이 검증 안내](../planning/target-practice-playtest-2026-10-31.md)에 있다. ‘다음에 무엇을 바꿀지 알겠는가’, ‘3회 뒤 한 번 더 던지고 싶은가’를 확인하면 된다. 성공 횟수만으로 재미가 검증됐다고 보지는 않는다.

## 구현한 범위

- 선택적 연습 표적 1개, 정면4m·반지름1m. 충돌체 없는 시작선·방향선·바닥 원이다. 초기 색종이1장과 기존 발견 기체1대는 그대로다.
- 발사 시 참여 여부에 해당하는 표적 중심/반지름을 복사해 보관한다. 모드 종료나 이후 이동으로 이미 던진 기체의 판정을 바꾸지 않는다. 시작선 밖은 빈 표적, 즉 자유 투척이다.
- 실제 물리 접촉 중 지면으로 표시한 공원 바닥/길만 기록한다. 접촉점은 엔진이 제공하는 충돌 상대의 월드 좌표를 사용한다. [Godot 공식 API 정의](https://docs.godotengine.org/en/4.3/classes/class_physicsdirectbodystate3d.html)에 따른 get_contact_collider_position을 실제 바닥 높이와 대조했다. 장애물 접촉과 첫 지면 접촉을 혼동하지 않는다.
- 첫 접촉점까지의 수평 거리는 **발사 COM의 지상 투영 → 실제 접촉점의 XZ 거리**, 표적 오차는 **접촉점 → 고정 표적 중심의 XZ 거리**다. 기존 정지확정 거리는 **발사 COM → 정지 확정 당시 COM의 XZ 거리**로 별도 표시한다. 접촉점과 COM이 달라 첫 거리가 정지 거리보다 약간 클 수도 있다.
- 최초 지면 접촉과 시간이 확인되지 않으면 ‘판정 불가’로 남긴다. 최종 정지점을 첫 접촉인 것처럼 사용하지 않는다. 취소·막힌 발사·수치 오류에는 연습 성공을 추가하지 않는다.
- 같은 실물에 최근3회 기록을 복원한다. 직전 궤적은 실제 월드 좌표의 주황색 선이며, 현재 궤적은 기존 색상이다. 궤적 샘플은 발사부터 정지 확정까지이므로 접촉 후 이동도 포함할 수 있다. 기체/용지/부위가 다르면 참고 기록으로 표시하고 이전 궤적을 같은 구성인 것처럼 그리지 않는다. 힘·목표각·날개·자세·발사 위치·바람 변화는 이름으로 표시하며 원인 단정 조언은 없다.
- 내 기체 회수는 바로 hand. 다른 손 기체는 stored로 보존한다. 새 발견물은 기존처럼 관찰→처리 선택을 거친다. 회수 범위에 걸어가는 조건은 유지한다.
- 비행·착지 관람 패널은166px 입력판에서104px 정보판으로 줄였다. 고도각 조작부와 바람 변경 버튼은 관람 중 숨기고 바람 방향·풍속은 유지한다. 복귀와 결과는 계속 사용할 수 있다.
- 공원 추적 기본 거리는 기존 preview_distance를 재사용해 max(1.2m, preview_distance×1.5)로 잡았다. 큰 종이는 그에 비례해 멀리서 본다. 가까운 카메라에 머리가 들어오지 않게 관람 중 캐릭터 외형을 숨기고 공원 복귀 시 복원한다.
- 3D 이름표는 짧은 한 줄로 줄이고, 근거리와 관람 중에는 숨긴다. 표식의 XZ는 실제 접촉점에 고정하고, 표시 높이만 max(실제 접촉 높이, 기록된 표적 중심 높이)+0.006m로 둔다. 현재 원의 면은 약0.0013~0.0017m이고 표식은 약0.008m여서 채움 위에 보인다. 마지막 높이 보완은 단독 GPU 캡처로 확인했으며 물리 좌표·판정값은 바꾸지 않았다.

기본 기체 형상·질량·힘/공력·정상 중력·1.7m 발사·3입력/20px 원점/고도각 편차·접기 편집·모달 차단·잡은 회전 링·오디오 성공/실패 규칙은 유지했다. 경제 보상, 자동 기체 제공, 자동 순간 회수, NPC, 여러 코스, 랜덤 발견, 영구 진행은 추가하지 않았다.

## 실제 반복 결과

기존 발견 기체 ID2를 관찰·보관 후 사용했다. 최초 배치만 테스트 준비로 지정하고, 이후 회수/시작선 왕복은 캐릭터 물리로 걸었다. 투척마다 실제 3입력 이벤트와 실제 엔진 착지를 사용했다. 자동 검사는 게이지 시간 진행을 직접 호출해 대기를 줄였으며, 기획 독립 검사에서는 실시간 게이지도 별도로 확인했다.

| 회차 | 힘 / 고도각 / 날개 | 첫 접촉 거리·시간 | 중심 오차 | 판정 | 정지확정 거리·시간 |
|---|---|---|---|---|---|
| 1 | 60% / 10° / 90° | 약4.15m / 1.67s | 약0.69m | 안 | 약4.13m / 1.95s |
| 2 | 60% / 10° / 110° | 약5.97m / 2.30s | 약2.21m | 밖 | 약6.03m / 2.68s |
| 3 | 60% / 10° / 90° | 약4.15m / 1.67s | 약0.87m | 안 | 약4.13m / 1.95s |

왕복 후 서 있는 위치도 조금 달라지므로, 위 조건은 발사 위치까지 완전히 동일한 실험이라고 주장하지 않는다. 결과창에서도 발사 위치 변화를 표시한다.

기획 측 독립 GPU 3회에서는 실제 게이지61/81/41%로 진행했다. 41%의 경우 최초 오차 약1.007m로 원 밖, 이후 정지 위치 오차 약0.951m로 원 안이었으나 판정은 밖으로 유지됐다. 위치를 강제로 바꾼 사례가 아니라 자연스러운 실제 물리 결과다. 별도로 고정 첫 접촉을 두 번 기록하려는 검사에서도 기존 점과 판정이 유지됐다.

## 완료와 남은 확인

로컬 프로젝트는 사용자 검증 가능한 상태다. 기능·실제 접촉·반복 흐름과 두 해상도의 GPU는 확인했지만, 사람의 손 조작과 재미 평가는 아직 남아 있다. 큰 종이/다양한 자작 기체·바람으로 장시간 반복한 재미와 표식 가독성까지 보장하지 않는다. 기록은 실행 세션 범위이며 새로 F5 실행하면 공원 실물/연습 기록은 초기화된다. 기존 저장 도면은 유지된다.

이번에 별도 브라우저 실행, 빌드 배포, 커밋·푸시는 하지 않았다. 물리 튜닝·새 설정 체계·추가 콘텐츠도 범위에서 제외했다.
