# Paper Airplane Park — 부위 지정과 비행 UI 검토 (2026-10-26)

후속 발사 조작 변경은 [팡야식 게이지 검토](pangya-gauge-2026-10-26.md)를 참고합니다. 아래는 첫 개편 시점의 기록입니다.

접기 화면에서 비행 부위를 지정하고, 비행 준비에서는 기체 중심의 화면과 단계식 발사 게이지를 사용합니다.
이번 변경은 로컬 검토용입니다. 커밋·푸시·Pages 재배포나 공개 설정 변경은 하지 않았습니다.

## 구현

- 비행 부위: 기존 접기 이력에서 날개 1·2, 기존 재료 면에서 손잡이 기준을 선택합니다. 민트·노랑·보라 색과 이름·외곽선으로 표시하며, 각 ‘강조 보기’ 버튼으로 가려진 층도 확인합니다. 90° 펼침 미리보기와 연결 검증 후 확정합니다.
- 처음의 마지막 두 연결부 추천과 실제 확정을 구분합니다. 확정 후 후보를 바꾸면 ‘변경 후보 / 미확정’이며 다시 확정하기 전에는 기존 지정을 유지합니다.
- 확정한 접기 인덱스는 저장된 이력의 실제 접기선/움직이는 면을 가리키며, 실제 3D 펼침과 손잡이 아래 기본 자세에 사용합니다. 마지막 두 접기를 다시 추정하지 않습니다. 다른 날개 순서를 확정하고 비대칭 각도를 적용하는 검사를 포함합니다.
- 종이와 이력의 기하 서명으로 유효성을 확인합니다. 상태가 달라지면 재확인을 표시하고 자동 추천으로 자유 비행을 유지합니다. 정확히 이전 상태로 되돌리면 기존 지정도 다시 유효합니다. 새 종이는 지정을 지웁니다.
- 프리셋/덤프에 부위를 보존합니다. 기존 프리셋은 추천/미확정으로 열립니다. 표시명을 바꾸어도 Windows·Linux·웹의 기존 Paper AirPlane 사용자 경로를 유지합니다. 기존 파일을 옮기거나 삭제하지 않습니다.
- 기본 비행 화면에는 작은 상단 조작, 오른쪽 결과 버튼, 하단 발사 게이지, 오른쪽 아래 바람 표시가 남습니다. 자세/날개 조정은 접을 수 있고 닫으면 회전 링도 숨깁니다. 좌우 발사 방향 UI는 제거했으며 초기 속도는 정면 0°를 유지합니다.
- 첫 입력은 힘 시작(1–100%), 둘째는 힘 확정 후 고도각(-80–80°), 셋째는 고도각 확정과 발사입니다. Enter/Space와 화면 버튼을 섞어 사용할 수 있습니다. 홀드/반복 이벤트와 같은 프레임의 중복 입력을 막습니다. 왕복 편도 시간은 힘 2.4초, 고도각 2.8초인 첫 시안입니다.
- 게이지 중 자세와 날개를 잠그며 취소는 이전 준비 값으로 돌아갑니다. 실제 초기 속도·고도각과 결과/덤프 값이 일치합니다. 임의 오차·타이밍 보너스·비행 물리 튜닝은 추가하지 않았습니다.
- 결과는 오른쪽 스크롤 팝업입니다. 열고 닫아도 초기화·재발사·시뮬레이션 정지가 일어나지 않고 새 결과가 자동으로 창을 열지 않습니다. 힘·고도각·거리·체공시간·기존 날개 각도·종료 이유를 표시합니다. 기록은 종전처럼 현재 비행 화면에서만 유지합니다.
- 바람은 실제 물리 소스의 0 m/s를 표시합니다. 무풍에서는 방향 화살표 대신 중립 점을 표시하며, 툴팁은 바람이 불어가는 방향임을 설명합니다.
- 1280×720과 640×360에서 실제 픽셀 크기를 사용합니다. 조정/부위/결과 내용은 스크롤하며 게이지와 바람·결과 영역을 분리했습니다.

## 검증과 한계

- 전체 자동 검사는 기존 접기 연결·층 순서·앞뒷면 GPU 픽셀·기본 비행기 가이드·프리셋·축 회전 검사에 새 UI와 부위 검사를 추가했습니다. 최종 GPU 검사 13,107개와 헤드리스 검사 12,403개가 모두 실패 0건으로 통과했으며 SCRIPT ERROR/ERROR 로그도 없습니다.
- [GPU 로그](../../build/park_gpu.log), [헤드리스 로그](../../build/park_headless.log), [웹 내보내기 로그](../../build/park_web_export.log), [브라우저 로그](../../build/park_web_browser.log).
- Edge/WebGL2 실제 브라우저에서 구 버전 웹 빌드로 저장한 프리셋을 같은 origin의 신 버전으로 다시 열었습니다. 한글 표시·기존 경로·부위 확정/저장·게이지 키 홀드/버튼 발사·실제 속도/고도각·결과 팝업·Esc와 640×360을 확인했습니다. 검사 중 생성한 웹 저장본은 격리된 테스트 브라우저 컨텍스트에만 존재합니다.
- 부위는 기존 기록 번호/면 목록으로 고르는 첫 구현입니다. 임의 다각형을 잘라 새 날개를 지정하거나 복잡한 새 접기 동작을 만드는 기능은 없습니다. 손잡이는 선택한 기존 면을 기준으로 합니다.
- 타이밍 속도와 조작감은 사용자 체감 검토가 필요합니다. Safari·실제 태블릿 터치·장시간 비행/목록 스트레스 검사는 하지 않았습니다. 이번 개편을 Pages에 재배포하지 않았습니다.
