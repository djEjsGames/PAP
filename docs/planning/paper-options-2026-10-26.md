# 용지 4종과 선택 UX — 2026-10-26

개발 반영과 검증은 [용지 4종 구현 기록](../reviews/paper-stock-implementation-2026-10-26.md)을 참고하세요. 아래는 승인된 요구와 설계 기준입니다.

## 사용자 확정 변경

- 새로 만드는 기본 색종이: **15×15cm 정사각형**.
- 새 비행의 기본 발사 높이: **지면 위 1.7m, 기체 무게중심 기준**.
- 향후 용지의 크기와 재질을 다양화하고 비행에 반영한다.
- 기존 도면·프리셋·덤프의 실제 치수를 소급해 축소하거나 발사 기록의 높이를 바꾸지 않는다.
- 사용자가 후속으로 **기본 색종이·A4 복사용지·신문지·얇은 도화지 네 종류의 구현을 승인**했다. 아래 네 종류와 선택 UX를 포함한 개발 요청이 최신 범위다.

## 구현할 네 가지 용지

아래 규격은 승인되어 게임에 반영한 비교용 값이다. 같은 이름의 모든 실제 제품이 동일 평량·강성을 가진다는 뜻은 아니다. 질량은 가로(m)×세로(m)×평량(g/m²)으로 계산했다.

| 용지 | 크기 | 평량 | 한 장 질량 | 기획상 역할 |
|---|---|---:|---:|---|
| 기본 색종이 | 15×15cm | 80g/m², 현재 모델 값 유지 | 1.80g | 새 기본형과 비교 기준 |
| A4 복사용지 | 21×29.7cm | 80g/m² | 4.99g | 직사각형 접기와 더 큰 기체 실험 |
| 신문지 (국내 대판 한 면) | 39.1×54.5cm | 45g/m² | 9.59g | 큰 면적과 낮은 평량 |
| 4절 도화지 (사륙) | 39.4×54.5cm | 120g/m² | 25.77g | 4절 규격과 높은 평량 |

큰 색종이20×20cm/80g/m², 크라프트15×15cm/90g/m²는 후속 후보로 남기며 이번 선택지에 추가하지 않는다. 기존20cm 도면의 호환은 별도로 보존한다.

현실 규격 참고:
- [Double A Premium](https://eu.doubleapaper.com/products/double-premium): A4 210×297mm, 80g/m².
- [Norske Skog NorNews](https://norskeskog-golbey.com/en/newsprint/nornews/): 45g/m² 신문용지 제품 규격 포함.
- [Canson XL Kraft](https://en.canson.com/xlr-kraft): 90g/m² 제품.
- [Canson 1557 120gsm](https://en.canson.com/1557-120gsm): 120g/m² 드로잉 용지 제품.
- [종이나라 FAQ](https://www.jongienara.co.kr/faq/general): 제품별 원지 평량 표기를 안내한다. 기본 색종이의 정확한 제품 평량은 별도 선택 전까지 기존 코드의 80g/m²를 유지한다.

## 비행에 반영하는 원칙

- 크기는 실제 기하·날개 면적·무게중심·관성에 반영한다. 크기만 바꾸고 물리 형상은 그대로 두지 않는다.
- 평량은 전체 재료 질량과 관성에 반영한다. 접힌 층이 겹쳐도 재료 질량은 유지하고, 공기력 노출 면적을 중복 계산하지 않는 기존 원칙을 유지한다.
- 무겁거나 비싼 종이가 항상 더 멀리 나는 상위 아이템이 되도록 보너스를 주지 않는다. 형상·자세·힘·바람과 함께 결과가 결정된다.
- 현재 강체 모델은 종이의 휘어짐을 직접 표현하지 않는다. 같은 크기·평량의 재질 차이를 휘어짐으로 구현했다고 설명하지 않는다. 후속 단계의 강성/접힘 유지력은 실제 샘플과 구현 범위를 확인한 후 결정한다.
- 모든 재료를 실측 없이 서로 다른 양력 배율·거리 보너스로 구분하지 않는다.
- 용지 선택은 새 종이를 시작할 때 하는 선택으로 두어, 반복 발사마다 새 선택 절차를 요구하지 않는다. 기존 도면을 불러오면 그 도면의 용지 조건을 따른다.

## 개발 전달 범위

기본 치수·발사 높이 수정과 함께 승인된 네 용지와 아래 선택 UX를 구현한다. 기본 색종이는 기존 평량80g/m²를 유지하고, 선택한 용지별 평량을 실제 질량·관성 계산에 사용한다.

- 가이드·기준점·스냅·최소 면적/선택 판정·부위 지정·화면 맞춤이 새 15cm 용지에서도 제대로 작동하도록 확인한다.
- 기존 20cm fixture와 실제 사용자 도면은 원래 치수를 유지한다. 테스트 기대값을 전부 0.04m²에서 0.0225m²로 일괄 치환하지 않는다.
- 새 기본 면적은 0.0225m², 기존 80g/m²일 때 질량은 0.0018kg이다.
- 1.7m는 새 발사 조건에 적용하고, 과거 덤프 재현 테스트는 저장된 높이를 따른다.
- 현재 진행하는 반복 플레이 UX 작업을 보존하고, 새 용지 선택 단계를 기존 반복 발사 흐름에 필수로 끼워 넣지 않는다.

## 종이 선택 UX

### 선택하는 시점

2026-10-31 갱신: 아래 초기 무료 지급·공원 새 용지 선택은 [종이 상점 구현과 검증](paper-shop-playtest-2026-10-31.md)으로 대체했다. 공원에서는 구매한 실물의 재료를 유지하고, 독립 실험 장면은 기존 무료 선택을 유지한다. 로컬 사용자 검증 준비가 완료됐으며 새 상점 버전의 공개 배포는 하지 않았다.

- 처음 시작할 때는 기본 색종이15×15cm를 바로 제공한다. 시작 화면이나 매 발사 때 선택 팝업을 강제로 띄우지 않는다.
- 현재 용지 요약 근처의 보조 행동 **새 종이**로 선택 창을 연다. 현재 요약은 예를 들어 `색종이 · 15×15cm`처럼 짧게 표시하며 하단의 주 행동을 밀어내지 않는다.
- 다시 던지기·비행 위치 복귀·부위 확인·접기 왕복에서는 선택한 종이를 유지한다. 용지를 바꾸는 것은 새 종이를 시작하는 행동이다.

### 화면과 선택 행동

- 네 카드를 한 번에 비교하는 **2×2 배치**를 기본으로 한다. 1280×720와640×360에서 카드 네 장과 시작·취소가 보이도록 구성한다. 긴 보조 설명만 접거나 스크롤한다.
- 각 카드에 실제 종이의 가로세로 비율을 반영한 작은 샘플, 이름, 크기, 한 장 질량, 짧은 설명을 표시한다. 평량은 작은 보조 정보 또는 상세 설명으로 둔다. 크기 비교가 오해되지 않도록 같은 비율/축척의 샘플 또는 명확한 수치 표기를 사용한다.
- 색종이는 색 면, A4는 흰 직사각형, 신문지는 일반적인 인쇄 패턴, 도화지는 옅은 종이 질감으로 구분한다. 외부 신문 기사나 브랜드 그림을 가져올 필요는 없다. 재질의 시각화가 날개 외곽·접기선·부위 강조를 가리지 않도록 한다.
- 카드 설명은 '기본 정사각형', '긴 직사각형', '같은 크기 색종이보다 가벼움', '같은 크기 색종이보다 무거움'처럼 확인 가능한 차이만 사용한다. 거리 보장·가상의 성능 막대·희귀도·상위 등급은 추가하지 않는다.
- 기본 선택은 현재 용지와 같은 항목, 대응 항목이 없는 기존 도면에서는 기본 색종이로 둔다. 선택 테두리와 체크를 함께 사용해 색만으로 선택을 구분하지 않는다.
- 카드를 누르는 동작은 **후보 선택/비교만** 한다. 실제 접기나 저장 상태를 바꾸지 않는다. 고정된 주 버튼 **이 종이로 시작**을 눌러야 새 종이와 해당 물성으로 확정한다. 선택 변경이 즉시 종이를 초기화하면 안 된다.
- 취소/Esc는 원래 종이·접기 이력·부위·카메라·비행 기록을 그대로 유지한다. Enter로 시작을 지원한다면 이미 누르고 있던 키가 창을 열자마자 선택 확정이나 발사로 새지 않게 한다.

### 현재 작업과 저장의 보호

- 기존 작업을 새 종이로 바꾸는 경우 선택 창 안에 현재 접기가 교체된다는 짧은 안내를 표시한다. 별도 확인 팝업을 연속해서 추가하지 않는다. 기존 미저장 작업의 보호 절차와 조화를 맞춘다.
- 미저장 도면에 필요하면 기존 내 도면 저장 흐름을 통한 **저장하고 시작** 보조 행동을 제공한다. 저장 취소/실패 시 새 종이를 만들지 않고 원래 작업을 보존한다.
- 프리셋/덤프는 용지 종류·가로세로 실제 치수·평량을 보존한다. 불러온 직후 현재 선택기의 기본값이 저장된 용지를 덮어쓰면 안 된다.
- 예전 메타데이터 없는 도면은 원래 재료 좌표의 치수와 기존80g/m²를 유지한다.15cm로 축소하거나 새 용지 종류로 임의 재분류하지 않는다. 요약에 '이전 도면'과 실제 치수를 표시해도 된다.
- 이전 비행 결과는 발사 당시 용지 종류/크기/평량을 따라야 한다. 새 종이 선택으로 과거 기록의 재질이나 질량을 바꾸지 않는다. 실행 중 결과 기록 유지 정책과 맞춰 비교 조건을 구분한다.

### 직사각형과 가이드

- A4를 정사각형처럼 자르거나 뷰에서 늘려 표시하지 않는다. 원래21×29.7cm 종이를 접고, 해당 물리 형상을 날린다.
- 색종이와 기존15cm 정사각형 도면에서는 기본 가이드를15cm에 맞게 사용할 수 있어야 한다. 기존 정사각형 가이드를 A4에 비균일하게 늘려서 같은 접기라고 표시하지 않는다.
- 이번 최소 범위에서 A4 전용 가이드가 없다면 기존 가이드가 정사각형용임을 알리고 자유 접기는 허용한다. A4 선택 자체를 막거나 정사각형으로 바꾸지 않는다.

## 추가 완료 기준

- 네 용지를 선택하고 기본 종이 면적·질량을 확인한다: .0225m²/1.8g, .06237m²/4.9896g, .213095m²/9.589275g, .21473m²/25.7676g.
- 평량 영향은 동일15cm 형상 단위 검사로 분리해 실제 질량·관성·공력에 대한 가속 반응을 확인하고, 실제 카탈로그는 각 용지의 원래 치수로 검사한다. 특정 종이가 항상 더 멀리 난다는 테스트는 작성하지 않는다.
- 선택/취소/Esc는 비파괴이며 시작 확정만 초기화한다. 새 종이→접기→부위→저장→불러오기→비행→재시도의 흐름에서 용지가 유지된다.
- 신형 프리셋/덤프는 용지 메타데이터를 왕복 보존하고, 예전20cm 프리셋·덤프의 치수/평량도 그대로 유지한다.
- 모든 새 비행의 기본 높이는1.7m이고, 과거 덤프 재현은 그 덤프의 실제 높이를 따른다. 접기 연결·앞뒷면 표시·게이지·바람·카메라 조작은 보존한다.
- 네 카드 선택 창/각 용지의 초기 종이/선택 취소/저장 불러오기/비행 요약을1280×720와640×360 PNG와 관련 검사 결과로 제출한다. 기존 웹 환경에서도 선택·저장·재시도를 확인하되 별도 공개 배포는 요청하지 않는다.

## 사용자 직접 요청 갱신: 15°와 큰 종이

도화지는4절39.4×54.5cm, 신문지는국내대표대판한면39.1×54.5cm로 새 선택에 적용한다. 평량120/45g/m²와 기존15cm파일은 유지한다. 2번 선 긋기에15°스냅을 추가하고 기준 스냅 우선·Shift 자유각도를 유지했다. [구현·규격근거·검증](../reviews/line-angle-paper-sizes-2026-10-26.md)이 최신 결과다.
