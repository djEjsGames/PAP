# 종이 상점·소지금 — 구현 및 플레이 검증 기준

2026-10-31. 사용자는 바닥 표적을 유지하면서 기본 색종이 지급을 제거하고 소지금→상점→종이 구매 단계를 추가하도록 요청했다. 현재 구현된 용지 전부를 판매하며, 더 나은 개선도 함께 적용하도록 승인했다. 제품 구현은 개발 세션, 기획·독립 교차검증은 이 세션에서 담당한다.

## 이번 경험

**용지의 차이를 보고 한 장을 고른다 → 작업대에서 접는다 → 표적에 던진다 → 같은 종이를 회수해 조절한다.**

구매는 재료를 확보할 때의 선택이다. 매 투척마다 지출하거나 접기 실패 때문에 종이를 잃지 않는다. 종이 구매가 기존 반복 투척에 새 필수 메뉴로 끼어들어서는 안 된다. 월드 발견 기체를 주워 활용하는 선택도 유지한다.

무제한 재고, 1장 단위 즉시 구매로 시작한다. 장바구니·묶음·희귀도·잠금 해제·복수 상점·판매·매입·대출은 만들지 않는다. 수입/봉사 보상은 이번 최소 구현에서 추가하지 않는다. 종이는 반복 사용하므로 우선 자금과 재료 선택의 관계를 검토한다. 돈과 실물은 기존 공원 세션 범위이며, 도면 파일은 별개로 보존한다.

## 동선과 화면

- 작업대 왼쪽 가까이에 식별 가능한 작은 종이 상점을 두고 가까이 가 E로 연다. 오른쪽 표적 동선과 구분한다. 캐릭터 NPC·외부 에셋 없이 현 스타일로 구현할 수 있다.
- 시작 HUD에 현재 잔액과 ‘종이 상점에서 구매 → 작업대에서 접기’를 짧게 안내한다. 강제 팝업은 열지 않는다.
- 상점에는 네 상품을 함께 비교한다. 실제 비율의 견본, 이름, 크기·질량, 평량/설명, 가격·보유 수량을 표시한다. 작은 창에서 정보가 겹치면 보조 설명을 스크롤하되 잔액·선택 상품·구매 행동은 읽혀야 한다.
- 카드는 후보 선택만 한다. 선택 종이와 구매 후 잔액을 보여주고, 명시적인 ‘1장 구매 · N코인’에서만 결제한다. 잔액 부족이면 부족액을 알려주며 구매하지 않는다.
- 구매 성공 시 실물 한 장을 보관함에 넣고 자동 선택한다. 구매 확인과 작업대 안내를 남긴다. 작업대까지 걷고 E로 바로 선택한 종이를 편집할 수 있어야 한다. 자동 이동·기존 기체 교체는 하지 않는다.
- Tab 보관함, Esc 닫기를 유지한다. 상점은 이동·시선·투척·발견물 관찰 입력을 가리고, 닫는 입력이 뒤의 다른 행동으로 새지 않게 한다. 한 번 누르고 있는 구매 키로 여러 장이 사지면 안 된다. 별도로 다시 누른 구매는 의도한 다음 구매다.

## 실물과 구매의 일관성

- 초기 무료 색종이는 실제로 생성하지 않는다. 빈 보관함에서 상점 안내와 구매가 동작해야 한다. 기존 고정 발견 기체는 유지한다. 테스트 호환을 위해 무료 종이나 가짜 슬롯을 숨겨 만들지 않는다.
- 정상 구매는 잔액 차감과 유일ID 실물 한 장 생성이 함께 성공해야 한다. 잘못된 상품·부족한 잔액·실패에서는 둘 다 보존한다. 잔액은 음수가 될 수 없다.
- 공원 편집의 새 종이·도면 불러오기·덤프 복원·가이드/초기화 경로가 같은 실물을 다른 크기·평량·재질로 무료 변환하지 못하게 한다. 최종 보관에서도 원래 재료와 맞는지 확인한다.
- 같은 재료 한 장에서 다시 펴거나 접기를 초기화하는 것은 허용한다. 같은 재료 도면의 접기 정보는 현재 한 장에 적용할 수 있다. 다른 재료 도면은 맞는 종이를 구매·선택하도록 안내하며, 암묵적 추가 결제나 형상 비율 변환을 하지 않는다.
- 독립 접기 실험 장면의 무료 용지 선택은 유지한다. 기존 도면·덤프·실물의 치수나 재질은 소급 변경하지 않는다.
- 구매한 같은 실물은 접기→보관→손→투척→월드→회수에서 보존되고 추가 차감되지 않는다. 처음 발견물은 기존 살펴보기와 처리 선택을 유지한다.

## 교차검증과 사용자 평가

구현 후 아래를 확인한다. 사용자 체감 체크는 자동 검사 통과와 별개로 비워 둔다.

1. 새 공원에 무료 종이0·잔액100, 빈 보관함/작업대에서 상점까지 안내가 이어지는지 확인한다.
2. 선택·Esc 취소는 무소비, 네 상품의 정상 구매는 각각 가격·크기·질량·유일ID·빈 typed 접기 이력을 보존하는지 확인한다. 네 장을 사면 잔액25다.
3. 부족/0잔액·잘못된 상품·반복키·모달 입력 차단과 수량 증가/차감의 일치를 확인한다.
4. 한 장 구매→작업대 접기→보관→Tab 꺼내기→표적 투척→실제 착지→걷기 회수·재시도에서 물성·ID·잔액을 확인한다.
5. 무료 재료 변환은 차단하고, 같은 재료 도면 적용/되돌리기/취소와 기존 독립 실험실은 보존하는지 확인한다.
6. 1280×720와640×360의 시작·상점·구매/부족·구매 후 작업대·표적 화면을 실제 GPU로 검토한다. 초기 지급과 고정ID를 가정하던 기존 회귀는 구매 fixture에 맞춰 갱신한다.

- [ ] 처음 돈과 종이가 별개라는 점을 알 수 있었다.
- [ ] 상점을 찾고 네 용지의 차이를 비교할 수 있었다.
- [ ] 선택한 이유를 크기·모양·가격 등으로 설명할 수 있었다.
- [ ] 구매 후 접기까지 보관함을 헤매지 않았다.
- [ ] 회수한 종이를 추가 구매 없이 다시 쓸 수 있음을 알았다.
- [ ] 구매 절차가 놀이의 준비가 됐고 번거로운 장벽처럼 느껴지지 않았다.

## 실행 순서

1. `D:\Works\Git\PAP\project.godot`을 열고 F5로 새 공원을 실행한다. 기존 실행 창은 종료 후 다시 시작한다. 새 게임은100코인·빈 보관함이며 바닥의 발견 기체는 남는다.
2. 작업대 왼쪽 초록 판매대로 걸어가 E로 상점을 연다. 카드 선택만으로는 돈이 줄지 않는다. ‘1장 구매 · N코인’을 누른다.
3. ‘닫기 · 작업대로’ 또는 Esc 후 작업대 앞에서 E. 방금 산 종이가 선택되어 편집된다. 기존 손 기체가 있었다면 그대로 보존된다.
4. 접기를 마치고 보관한 뒤 Tab → 해당 종이 선택 → 꺼내기. 오른쪽 시작선으로 걸어가 T, Space로 준비한다. 색종이 기본 가이드 기체의 첫 참고값은 무풍·목표각10°·힘 약60%·날개90°다. 다른 종이의 성능 보장값이 아니다.
5. 착지 결과를 보고 B → 기체까지 걸어가 E로 회수한다. 추가 지출 없이 같은 기체가 손으로 돌아온다. 시작선으로 돌아와 Space로 재준비한다.
6. 재료를 비교하려면 상점에서 다른 종이를 사 작업대에서 접는다. 크기와 모양이 다르므로 정사각형 도면을 다른 크기에 자동으로 늘려 적용하지 않는다.
